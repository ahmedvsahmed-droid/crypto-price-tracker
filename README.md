# Crypto Price Tracker

A simple Python-based cryptocurrency price tracking system using the Binance API.

This project fetches live cryptocurrency prices continuously and stores historical price data locally in JSON format.

---

## Features

- Live cryptocurrency price tracking
- Multi-coin monitoring
- Automatic refresh loop
- Timestamped logging
- JSON-based data storage
- Error handling for API/network issues

---

## Tracked Coins

- BTCUSDT
- ETHUSDT
- SOLUSDT

---

## Technologies Used

- Python 3
- Requests library
- Binance API
- JSON logging
